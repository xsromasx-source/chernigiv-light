# Графік світла — Чернігівщина

Неофіційний сайт з актуальним зображенням графіка погодинних відключень із публічного Telegram-каналу [@chernigivoblenergo](https://t.me/chernigivoblenergo).

Відкриття сайту: https://xsromasx-source.github.io/chernigiv-light/

Оновлення запускається GitHub Actions за розкладом (~5 хвилин, можливі затримки). Скрипт читає лише публічну сторінку https://t.me/s/chernigivoblenergo без Telegram-акаунта. Якщо Telegram змінить формат HTML чи обмежить доступ, оновлення припиниться; тоді перевіряйте [офіційний канал](https://t.me/chernigivoblenergo).

## Публікація
Відкрийте **Settings → Pages → Build and deployment → Source → GitHub Actions**, потім у **Actions** запустіть **Оновити графік і сайт → Run workflow**. Після успішного розгортання з'явиться вебсторінка.

Розклад може запускатися з затримками або не виконуватися за високого навантаження GitHub; сайт показує дату останньої успішної перевірки. Зображення графіка може стосуватися завтрашнього дня. Для конкретної адреси дивіться https://chernihivoblenergo.com.ua/blackouts.

Сайт не належить енергокомпанії.
